# Spice Haven Promo Portfolio

A promotional poster design portfolio site showcasing restaurant/food offer campaigns — built as client sample work for freelance social media design outreach.

## About

This single-page site presents a small collection of restaurant promotional poster designs (weekend offers, combo campaigns) as a portfolio for freelance design work. It's built to be shared directly with potential clients as proof of design capability.

## Features

- Full-bleed hero section with headline and call-to-action
- Large, cover-fit showcase of each poster design with captions (offer type, format, palette)
- "How it comes together" process section explaining the design workflow
- Responsive layout — works on mobile, tablet, and desktop
- Light/dark theme support
- Self-contained single HTML file — no build step, no dependencies

## Tech Stack

- Plain HTML, CSS, and vanilla JS
- Google Fonts (Fraunces + Work Sans)
- Images embedded inline (base64) for easy hosting anywhere

## Usage

1. Open `index.html` directly in a browser, or
2. Upload it to any static host (Hostinger, Netlify, GitHub Pages, etc.)
3. No build tools or dependencies required

## File Structure

```
├── index.html    # Complete self-contained portfolio page
└── README.md     # This file
```

## Customization

- Update the brand name in the header (`.mark`) and hero copy
- Replace poster images and captions in the `.piece` sections under `#work`
- Adjust colors via CSS custom properties in `:root`
- Edit contact CTA and links in the footer/`#contact` section
